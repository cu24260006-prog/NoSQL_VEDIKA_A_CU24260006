NOSQL DATABASE DESIGN - LAB SHEET 1
MongoDB Practical 1 to 25
================================

This folder contains 25 separate MongoDB Shell script files:
1.js, 2.js, ... 25.js

Each file corresponds to one practical from the teacher-provided PDF.
The practicals are kept in the original order and use MongoDB Shell
(mongosh) commands. They are not Python programs.

REQUIREMENTS
------------
1. MongoDB Server (Community Edition) installed and running.
2. MongoDB Shell (mongosh) installed.
3. No Python package or external library is required.

HOW TO RUN
----------
Open Command Prompt / Terminal in this folder and run a practical:

    mongosh "mongodb://localhost:27017/" 1.js

To run the next practical:

    mongosh "mongodb://localhost:27017/" 2.js

Replace the number with the required practical file number.
If MongoDB uses a different connection string, replace the address
above with your MongoDB connection URI.

PRACTICAL ORDER
---------------
1. Show all databases in MongoDB.
2. Select college database and show all collections.
3. Insert one student document.
4. Insert multiple student documents.
5. Display all student documents.
6. Find a student using Roll Number.
7. Find all students belonging to BCA.
8. Display only Name and Course of BCA students.
9. Update the course of Roll No. 102.
10. Update the semester of all BCA students to 6.
11. Replace the complete document of Roll No. 103.
12. Add an Email field to all students.
13. Remove the Email field from all students.
14. Delete the student with Roll No. 105.
15. Delete students having CGPA less than 8.
16. Count total student documents.
17. Rename Students collection to StudentDetails.
18. Create a Departments collection.
19. Drop the Departments collection.
20. Drop the complete college database.
21. Create college and Students again, then insert three students.
22. Find students whose CGPA is greater than 8.5.
23. Find students whose CGPA is less than 9.
24. Find students whose CGPA is greater than or equal to 8.5.
25. Find BCA students whose CGPA is greater than or equal to 8.5.

NOTES
-----
- The scripts use db.getSiblingDB("college") to select the college
  database inside a JavaScript file. This is the script-friendly
  equivalent of typing "use college" in the interactive mongosh prompt.
- The scripts use MongoDB Shell JavaScript syntax. For example, the
  first practical uses db.adminCommand({listDatabases: 1}) to list DBs.
- Run practicals in order if you want to follow the teacher's workflow.
  Some practicals depend on collections or documents created earlier.
- Practical 17 renames Students to StudentDetails. Practical 18 and 19
  create and drop Departments. Practical 20 drops the complete college
  database. Practical 21 recreates the database and Students collection.
- WARNING: Practical 20 permanently deletes the college database.
  Run it only when you intend to remove that database.
- The PDF's sample outputs assume a particular starting database state.
  Your output may differ if your MongoDB server contains other data.
- ObjectId values are generated by MongoDB and will differ on each run.
